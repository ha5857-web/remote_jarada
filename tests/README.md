# 자동 시험

고칠 때마다 GitHub가 알아서 돌립니다(Actions 탭 → 「자동 시험」). 초록 ✓ 이면 통과, 빨간 ✗ 이면 무엇이 깨졌는지 눌러서 볼 수 있습니다.

- `checks/` — 규칙 확인: 모든 화면이 오류 없이 열리는지, 보안 점검에서 고친 것이 다시 풀리지 않는지, 취소 예약 숨김·초진 7일·카드 QR 차단·치료 이력 읽기 같은 계산 규칙
- `scenarios/` — 실제 화면을 처음부터 끝까지 눌러 보는 시나리오(카드, 예약, 성장 리포트, 휴대폰 화면 …). 목록은 `scenarios/list.json`
- 서버·CDN은 모두 가짜로 바꿔서 돌리므로 실제 환자 정보나 실제 서버는 쓰지 않습니다. 시험 속 이름은 전부 지어낸 것입니다.

직접 돌리기: `cd tests && npm ci && npx playwright install chromium && npm test`

## 공용 파일 (`shared/`)

- `shared/fv-common.js` — 초진 기록지 읽기·영상 선별 (의사 앱 + 원무과 앱)
- `shared/chart-common.js` — 차트 글 나누기·생활 안내 초안 (의사 앱 + 현황판)

공용 파일을 고치면 쓰는 화면이 함께 바뀝니다. 고친 뒤에는 HTML의 `shared/…js?v=날짜` 숫자를 올려야 브라우저가 새 파일을 받습니다.
